# Pre-launch gates

- Fluent Tanzanian Swahili speaker reviews every copy key and human narration; child language comprehension test follows.
- Educators map each question and game to current TIE pre-primary and Cambridge Early Years/Primary learning outcomes. The present sample content is not a certified syllabus mapping.
- Children's privacy lawyer reviews COPPA, UK Children's Code, GDPR-K, Tanzania and destination-market privacy rules, optional data export/deletion, and the parental gate.
- Store/consumer lawyer checks the 3-day trial, $2.99 weekly auto-renewal, $19.99 lifetime offer, localized disclosure, reminder, refund and cancellation path in each market. Weekly plans for a child-directed app need special scrutiny.
- Recheck the latest Apple App Review Guidelines (Kids Category, IAP, subscription terms), Google Play Families Policy, target-age declaration, data safety forms, and both stores' children's category submission requirements immediately before submission.
- Provision native bundle IDs, products, server verification credentials, signing, support/privacy URLs, store screenshots and sandbox testers. Run full device and store QA.
- Review the current dependency audit before release. The scaffold currently reports 10 moderate transitive advisories in Expo build tooling/`uuid`; avoid a forced major downgrade and recheck for upstream patches.
